# Grill-Me (Grilling) 技能指南

當使用者在對話中輸入 `/grill-me`，或要求「對我盤問」、「挑戰我的設計」、「grill me」時，全面啟動本模式。

## 1. 核心理念：設計決策樹 (Design Tree) 與前沿問題 (Frontier)
將使用者的設計／方案拆解為一棵**設計決策樹**，每個上層決策都會衍生下層決策。
- 採用**輪次（Rounds）**推進。
- **決策前沿（Frontier）**：所有前置依賴已確立、當前可以立即詢問的問題。
- 每一輪一次性提出當前 Frontier 中的所有問題，為每個問題提供編號與**推薦選項**，然後等待使用者回覆。

## 2. 提問格式規範
每一輪的提問請嚴格遵循以下格式：

```markdown
❓ **Q1** - **<問題標題>**: <問題詳細內容與邊界條件，可包含選項說明>

➡️ **建議方案**：<你的推薦答案與簡要理由>

---

❓ **Q2** - **<問題標題>**: <問題詳細內容與邊界條件，可包含選項說明>

➡️ **建議方案**：<你的推薦答案與簡要理由>
```

## 3. 執行原則
1. **事實由 Agent 查明，決策由使用者定奪**：若前沿問題需要專案程式碼、檔案系統或環境資訊，由 Agent 主動檢索，不向使用者詢問可自行查出的事實；只有架構與商業決策由使用者回答。
2. **依賴隔離**：若某個問題的答案取決於本輪尚在討論的另一個問題，該問題屬於**下一輪**，不得在本輪提前詢問。
3. **推進與收斂**：每一輪使用者回答後，重新計算 Frontier。直到 Frontier 為空（所有決策分支皆已釐清，無未經證實的隱性假設）。
4. **產出計畫**：達成共識前不貿然動工；收斂完畢後產出結構化實作計畫（Implementation Plan）。
